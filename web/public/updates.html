2026-10-04功能与体验更新

独立共享面板与 Windows 客户端发布

  • 新增独立共享面板，支持邮箱注册、登录、密码重置，以及共享房间管理和访问密码。
  • 接入 QQ 平台，完善 KOOK 与黑盒语音的绑定、共享状态和管理流程。
  • 更新首页、共享页、观看页及管理面板的布局和交互，改善移动端使用体验。
  • 管理后台增加使用统计和记录查询，方便查看共享与观看情况。
  • 首页和分享页新增客户端下载入口，首次使用即可下载安装。
  • Windows 客户端支持共享窗口或屏幕、选择程序声音和麦克风，并在「关于」中查看版本和检查更新。
2026-08-24功能更新

黑盒语音绑定流程升级

  • 新增浏览器确认码绑定：在绑定页面获取确认码，由房间主回到房间发送后完成授权。
  • 支持通过 /xchelp 打开管理或绑定入口，也可用 /xchelp 加确认码完成绑定。
  • 兼容普通文本中的「屏幕共享」「共享屏幕」「屏幕分享」和 /xc，让发起共享更方便。
2026-08-23功能更新

黑盒语音接入与连接稳定性

  • 接入黑盒语音房间，增加独立的房间配置、共享卡片和共享状态同步。
  • KOOK 与黑盒语音各自保留房间配置和共享状态，跨平台使用时互不影响。
  • 改善机器人断线检测与自动重连；房间同步异常时保留已有绑定和配置。
2026-07-29功能更新

页面通知与机器人稳定性

  • 共享页、观看页和机器人管理面板新增重要通知，方便及时了解服务变化。
  • 改善 KOOK 机器人响应稳定性，减少消息重复和偶发无响应。
2026-07-25功能更新

共享卡片与画质权限优化

  • 真正开始共享后再向频道发送观看卡片；短暂中断恢复后继续使用原卡片。
  • 共享结束后更新原卡片，未开播的会话不会产生公开观看卡片。
  • 共享者可选画质与机器人管理面板开放的档位保持一致。
  • 机器人管理员可在管理面板选择本服务器启用的共享触发词。
2026-07-21初期功能

屏幕共享与观看体验

  • 通过 KOOK 机器人发起屏幕共享，观众点击链接即可观看，无需注册。
  • 支持多档画质与低延迟模式，机器人管理员可分别配置各服务器的声网服务。
  • 改善移动端全屏、静音及音量控制，增加声音播放受限时的点击开启提示。
  • 支持在兼容的浏览器和系统中共享窗口声音，具体能力以浏览器选择器为准。
