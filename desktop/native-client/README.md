# XgoatCast 原生 Windows 客户端 0.0.1-beta.2

使用 Windows x64 安装包安装，无需安装 .NET 或登录账号。
请勿单独移动 EXE：旁边的 DLL 必须保留。

安装包和更新清单的发布流程见 [Windows 客户端发布与更新](../../docs/WINDOWS_CLIENT_RELEASE.md)。客户端启动时及运行期间每六小时会检查 `https://cast.xgoat.top/downloads/windows/latest.json`，托盘菜单也可以手动检查更新。发现新版本后显示「立即更新」，点击打开发布页；选择「稍后」后可从菜单继续更新。

1. 未从网页唤起时显示 480 × 260 等待窗口，底部为独立状态栏。没有主动共享按钮或窗口内系统设置入口。首次运行会注册网页唤起协议；之后网页可以启动未运行的客户端。
2. 网页接入后自动切换为 1000 × 820 共享设置面板，选择画面、画质和声音。共享成功后自动收起为 560 × 480 预览窗口。超时、结束、错误、无可用画质或无可共享来源时返回初始小面板；未选中来源仍保留设置界面。可继续共享的正常停止会恢复设置界面。
3. 收起后的主要区域显示正在共享的画面，等比缩放并保留完整内容。预览只读取同一条屏幕共享轨道，最多每秒更新 5 次、640 × 360 像素，不改变发送画面。尚未收到画面时显示明确占位；静止画面保持显示，停止、切换或失败时清空预览。
4. 观看人数位于预览下方。共享中仅在零人观看且服务器提供 noViewerRemainingSec 时，紧跟人数显示“（xx秒后自动停止）”，本地按单调时钟递减并最低为零；有人或无期限时不显示括号。准备共享的 idleRemainingSec 倒计时仍在开始按钮里。
5. 收起后麦克风和程序声音位于右侧图标栏，可以直接点击开关、滚动查看、悬停辨认程序。画质、画面偏好和低延迟不显示。每次网页唤起都会将程序声音和麦克风重置关闭。
6. 控件采用中性灰白底、小圆角和明确的层级：开始共享使用橙色实心按钮，辅助操作使用轻量图标按钮，模式使用分段选择，画质使用自绘下拉菜单。声音、麦克风和低延迟采用 20 像素小圆角复选框，收起态仅突出已开启的声音图标。标题栏、托盘、任务栏和 EXE 文件图标统一使用橙底 🐑，文字采用细字重。
7. 关闭窗口或按 Escape 隐藏到托盘，共享继续。Tab / Shift+Tab 与空格、回车可操作按钮。状态切换时清除旧命中区并取消按压，立即释放鼠标捕获。

麦克风下方显示当前设备，点击使用自绘菜单选择系统默认或实际输入设备。默认设备跟随系统变化，设备断开时回退默认；切换设备不主动开启麦克风。展开窗口为 1000 × 820，右栏 264 像素，等待面板为 480 × 260，等待文字居中。

画质、低延迟、画面偏好和麦克风设备选择保存在 `%LOCALAPPDATA%\XgoatCast\settings.json`。不会保存共享令牌或自动恢复旧窗口。DirectWrite / ClearType 文字和 Per-Monitor V2 DPI 感知；各状态布局按当前工作区适配窗口大小，紧凑态不再被展开尺寸限制而额外缩小。

## 系统与限制

- 推荐 Windows 11 x64。软件音频过滤要求 Windows build 20348 以上；普通 Windows 10 上仅提供无声画面共享。
- 不透明浅色背景保证文字对比度，没有附带 WebView/Electron。
- 声音允许名单通过进程名及进程树判断，每 250ms 更新。进程改名、沙盒和软件升级需要实机兼容性检查；不承诺所有软件结构零泄漏。失败时停止共享，不降级为未过滤的系统声音。
- 仅采集明确选中的程序。QQ 音乐的同安装目录子组件归为一个程序，后启动组件继承 QQ 音乐开关；其他未选择的不同程序子进程仍会阻止宽泛的程序树采集。麦克风单独开启，不改变自己听到的程序声音。
- 原型尚未签名，Windows 可能显示未知发布者提示；不要关闭系统安全防护。
- 移动文件夹后运行新位置的客户端一次，会更新网页唤起路径；若已启用开机启动，也应在新位置重新开启。删除前可从托盘取消注册。
- 浏览器无法可靠静默检测任意协议是否安装；现有网页通过唤起及会话状态反馈协作，不保证自动安装检测。
- 此版本尚需真实房间双端验收、真实语音软件兼容性及长时间共享测试。不会改动现有登录或令牌设计。

## 构建

需要 Node.js 20+、MSVC x64 C++ 工具链和 Windows SDK。依赖下载：

```text
node fetch-deps.cjs
node build.cjs
```

在 x64 Developer Command Prompt 中执行；也可提供 `--toolchain=路径/setup_x64.bat`。WSL 开发时还需 `--stage=/mnt/c/某个构建目录`，不能直接从 Linux 文件系统调用链接器构建。

生成目录是 `out/XgoatCast-win-x64`。可用 CMake 编译，但分发 DLL 的收集由 `build.cjs` 完成。执行 `node build-installer.cjs` 使用 Inno Setup 6 生成安装包，同名版本拒绝覆盖。

Windows 下执行 `node test.cjs [EXE路径] [Tone.cs路径]`，检查 URI、安全过滤策略、窗口启动退出、SDK 初始化/自定义音轨/窗口句柄枚举，以及三个专用测试进程的真实 WASAPI 音频过滤。SDK 自检使用虚构 App ID，窗口枚举不读取缩略图。测试会播放短暂音调，仅采集这些测试进程，不连接房间、不注册协议、不修改开机启动。

现有 Electron 原型保留在父目录，便于对照；本目录的发布包不依赖它。

## 本地调起与观看联调页

仓库根目录的 `.env.native-test` 保存本地临时声网配置并已被 Git 忽略。启动：

```text
npm run test:native-page
```

浏览器打开 `http://localhost:3531`，点击「调起 Windows 客户端」。客户端开始共享后，页面状态会变绿；点击「加入观看」可验证实际远端画面和软件声音。测试后台只绑定 `127.0.0.1`，会话存在内存中，重启即失效；App Certificate 不会返回给网页。正式部署不得复用此测试服务或临时证书。

临时测试服务器默认只开放 720p30、1080p30、1080p60。可在 `.env.native-test` 设置 `XGOATCAST_TEST_ALLOWED_QUALITIES=720p30,1080p_2,1080p60` 后重启测试服务。正式服务器依然使用自己的画质权限；客户端从唤起 URL 对应服务器的 `/api/share/info` 获取列表，不采用网页传入的画质，也不会自行补齐档位。

## UI 回归检查

Windows Node.js 下运行 `node test-ui.cjs [EXE路径] [输出目录]`，生成设置、150% DPI、等待、准备、共享中和无人观看倒计时预览。检查自动布局切换、无手动展开入口、条件倒计时、声音图标交互与滚动、预览布局、指针取消、悬停提示、布局边界、标题栏命中区和语义色对比，并执行协议／音频策略／预览帧处理自检和启动退出检查。UI 渲染使用合成画面，不连接房间、不注册协议、不采集屏幕或声音。

等待窗口为 480 × 260，共享预览为 560 × 480，设置面板为 1000 × 820 逻辑像素；150% DPI 的设置预览为 1500 × 1230。真实房间双端观看、跨显示器 DPI 和长期共享仍需实机验收。

实时预览链路另可执行 `XgoatCast.exe --preview-test 输出报告.json`：只创建并采集一个专用 320 × 180 纯色窗口，验证视频帧由红色更新为蓝色；不采集桌面、不启用麦克风、不加入房间。测试窗口会短暂显示，完成后自动关闭。

界面恢复双列屏幕／窗口卡片；点击来源切换为大预览，使用“更换画面”返回。右上集中分辨率、画面偏好、低延迟和麦克风，下方为程序音频。画质使用自绘菜单，支持键盘、Esc 与外部点击关闭；托盘菜单在托盘图标旁独立弹出，包含停止、开机启动、协议注册和退出，移除了“打开共享控制”。标题标志为 🐑，等待共享倒计时并入开始按钮。设计约定见 DESIGN.md；最新验收图位于 out/ui-compact-mic-08，画面内容为测试夹具。
