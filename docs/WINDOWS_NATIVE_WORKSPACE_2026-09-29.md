# Windows 客户端工作区重排 · 2026-09-29

本轮替代同日机械控制器布局。实现位于 `desktop/native-client/main.cpp`，继续使用现有 C++ 原生绘制与共享会话逻辑。

- 紧凑态保持 480 × 512：橙色左栏显示服务器倒计时和观看人数，右侧显示会话状态、画面摘要与操作。
- 展开态改为 1200 × 820：上方放置橙色倒计时卡、会话信息与开始／停止操作；下方主要空间留给画面选择，声音独立放在右侧。画质与画面偏好位于画面区底部，低延迟位于声音区底部。
- 金属材质缩为标题栏中的 32 × 32 品牌徽记，两种布局位置相同。删除固定在旧紧凑面板右上角的大金属片。
- 主操作采用深墨色，次操作采用浅色，选中状态采用浅橙色与较深的橙色边界。移除按键黑色硬底边、上浮位移和闪电扩散效果；控件使用轻阴影、8px 圆角、150ms 状态反馈。
- 客户区完整铺底，只绘制一条细边界，取消全窗口 DWM 玻璃扩展；不再产生旧的白色外围空隙。
- 展开／收起同步切换最终尺寸，无展开计时器或中间帧。切换时释放鼠标捕获，清除旧焦点和提示，再按新布局绘制命中区域。
- 标题拖动排除实际按钮区域；滚轮根据共用的画面／声音矩形分配。两种窗口尺寸分别适配当前显示器工作区。

## 验证

MSVC x64 构建通过。Windows Node 运行 `test-ui.cjs`，使用同一原生绘制代码生成展开、150% DPI、等待、准备、共享、无人观看倒计时预览。

交互回归通过：立即展开和收起、系统关闭动画、指针拖出与取消、画面选择、紧凑态隐藏设置命中区、控件边界和交叠、标题栏命中、画面／声音独立滚动、共享中画面参数禁用、悬停提示、倒计时归零／无期限／小时格式、语义色对比。协议和音频策略自检及启动退出检查也通过。

输出：`desktop/native-client/out/ui-redesign/`；绿色包：`desktop/native-client/out/XgoatCast-native-0.2.3-win-x64.zip`。
