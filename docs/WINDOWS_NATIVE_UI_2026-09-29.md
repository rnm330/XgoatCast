# 原生客户端三栏界面

- 未唤起：420 × 240 逻辑像素等待窗口，仅品牌、窗口控制、等待提示和主页链接。
- 已唤起：1120 × 760 三栏面板。左侧音频程序独立滚动，顶部麦克风及底部设置固定；中间默认屏幕选择和两行画质；右侧低延迟、共享偏好和会话状态。
- 文字采用 DirectWrite、ClearType 和自然双向抗锯齿，不透明背景提供稳定对比度。Per-Monitor V2 重新绘制并限制窗口在显示器工作区内。
- 每次唤起清空声音选择和麦克风。允许名单不继承旧排除配置，点击后 280ms 底部高亮；共享时可动态开关。程序图标来自 EXE，无法读取时用默认线框程序图标。
- 采集仍采用进程树回环，未知的未选择子进程会使该树被保守跳过。系统目录下的真实 conhost.exe 是控制台辅助进程，不作为独立声音软件屏蔽。SDK 音轨改为可混合类型，支持麦克风与程序声音同时发布。
- 每两秒从 `/api/share/info` 获取与网页相同的观看人数、idleRemainingSec 和 noViewerRemainingSec，本地按单调时钟更新剩余秒数；HTTP 错误优先显示服务端 message。停止后的待共享阶段继续读取会话期限。

## 验证

MSVC x64 编译通过；原生测试通过 URL 校验、默认拒绝/指定允许/新增子进程隔离、100% 和 150% 渲染尺寸、待唤起窗口、启动退出、SDK 自定义混合音轨初始化，以及真实 WASAPI 合成音源测试。

三路合成音源测试：默认关闭时三路幅度均为零；仅选择媒体测试程序后保留 440Hz，880/1320Hz 小于基准的 0.04%；运行中取消选择后音频静音。测试只捕获专用测试 PID，未加入实际房间。

最终文字抗锯齿调整后重新编译，并重绘检查普通、150% 和等待三张预览。预览中的显示器和程序列表为测试数据，不是真实桌面截图。

报告和预览位于 `desktop/native-client/out/ui-preview/`。真实房间双端、麦克风混音、真实语音软件及跨物理显示器 DPI 切换尚未联调。

## 暖白 / 莫兰迪橙调整

本轮只调整 `desktop/native-client` 的原生客户端界面。参考用户所附三栏仪表盘图片的空间分配，以及 https://ai-product-studio-34.aura.build/ 加载后的页面：胶囊按钮、内高光、柔和投影、约 300ms 悬停上浮。客户端采用自己的 260ms 三次缓出过渡。

- 当前主面板为 1420 × 920 逻辑像素；等待窗口仍为 420 × 240。左栏 248px、中区 788px、右栏 278px，保持音频、画面、会话控制分工。
- 画布 #F7F6F3，面板 #FFFEFC，橙色 #B56849，选中底 #F6E8DD；小号橙色文字使用更深的 #975035。主按钮白字与最浅背景对比约 4.53:1，选中橙字与底色约 4.98:1。
- 标题区加入原生矢量绘制的黏土风小屏幕，右侧状态区加入低对比度环形底纹。装饰不参与点击，也不覆盖画面内容。
- 按钮悬停上浮、阴影加深；按压下沉、松开复位；开关滑动、选中底色过渡。260ms 过渡结束停止 16ms 刷新，常规会话计时仍每秒刷新；遵循 Windows 客户区动画设置。
- 按下与释放必须命中同一控件；失去捕获会取消按压。支持反向 Shift+Tab。缩略图标题和命中区域完整纳入滚动区域，选中项提供勾选标记。

验证：MSVC x64 构建；普通、150% DPI 和等待窗口由实际原生绘制代码生成 PNG；URL / 音频策略自检；启动并自动退出的 smoke 检查。最新结果保存在 `desktop/native-client/out/ui-preview/ui-morandi-tests.json`。预览来源及程序列表为测试数据，灰色缩略图是无图像时的占位图。

Windows computer-use 工具因 `sandboxCwd is not a local file URI` 无法连接，重置后仍失败。本轮没有完成真人鼠标操作、跨物理显示器切换或真实房间验收；静态预览不代表已验证动态动画的实际帧率。
