## 未验证与限制

- 未使用真实房间进行双端推流、观看端音画同步、掉线恢复与长时间续期验收。
- 模拟进程音源不是实际 KOOK/黑盒多人通话，不代表所有软件版本、沙盒/子进程结构或设备切换已兼容。
- Windows 界面检查技能工具在当前 WSL 路径报 `sandboxCwd is not a local file URI`；重置重试仍失败，因此不能宣称已完成截图、玻璃效果、点击操作和多 DPI 可视化验收。
- 未签名原型。普通 Windows 10 不支持进程音频过滤；建议 Windows 11 x64。
- 编译测试没有修改系统协议、开机启动或生产部署；用户第一次运行时在界面启用即可。
