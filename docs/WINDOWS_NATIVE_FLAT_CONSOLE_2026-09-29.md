# 机械控制器：倒计时与独立声音栏 · 2026-09-29

当前稿遵循用户最后一轮修正，替代同日的观看人数大色块、常驻帮助文字、灰色拉丝片与底部声音列表。

- 橙色整条用于会话剩余时间，观看人数缩为画质旁的人形图标与数字。准备与无人观看期限使用现有 API 数据，本地只负责递减显示；有观众且不存在结束期限时显示 ∞。无会话或等待期限数据时显示 —。不创建新的共享限时。
- 面板为 #FAFAF8 的亮白纯色，按键维持 4px 小圆角及 2px 硬边行程。顶部小片采用按 DPI 缓存的银色放射反射材质，没有把反射渐变铺到其余面板。材质缓存在 GDI+ 关闭前释放。
- STANDBY 等字样置于暗色灯窗内，琥珀、绿色、蓝色、红色区分准备、共享、连接、异常。局部灯芯高光提供点亮效果。
- 状态说明、操作提示、完整名称、禁用原因在指针停留 420ms 后显示。点击、移出和开始展开时清除提示；提示单独最后绘制，避免其他延迟绘制文字穿透背景。
- 展开区域包含独立 240px 程序声音侧栏。六个可见按键独立滚动，图标、边条、机械勾选框区分启用状态；无模拟音量柱。麦克风与低延迟仅放在展开侧栏顶部，紧凑态既不绘制也不保留命中区域。
- 主状态信息与动作随壳体高度靠下排布；画面偏好移动到画质区域。

尺寸：紧凑 480 × 512，展开 1420 × 820；150% 测试 2130 × 1230。字体在展开动画中保持比例。

## 验证

Windows Node.js：`node desktop/native-client/test-ui.cjs [EXE路径] [输出目录]`。原生回归覆盖六种窗口状态、指针取消、来源选择、独立声音栏、隐藏控件、420ms 悬停出现与移出消失、倒计时格式／归零／无期限、关闭系统动画、展开中间帧、语义色对比、协议／音频策略和启动退出。

测试使用合成来源列表，不采集桌面或声音、不加入房间、不注册协议。预览与结果位于 `desktop/native-client/out/ui-countdown-console/`。

原生测试未替代实际鼠标操作、真实房间倒计时／观看人数变化、多显示器 DPI 切换和动画帧率验收。Windows computer-use 连接在当前 WSL 工作目录受限。本轮未修改服务端会话期限或采集逻辑。
