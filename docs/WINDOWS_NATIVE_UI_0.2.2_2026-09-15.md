# Windows 原生客户端 0.2.2

## 本轮调整

- 屏幕/窗口源改为紧凑纵向列表，每行 128 × 72（16:9）缩略图，上下滚轮、上下按钮和位置条；滚轮仅在画面选择区域生效。
- 禁用 Windows 11 默认外边框颜色，背景绘制覆盖客户区边缘，避免双重圆角留下灰角。
- 声音区域改名「屏蔽下列软件声音」，使用静音图标与「已屏蔽 / 未屏蔽」文案。
- 其他软件改为独立管理面板，支持英文进程名搜索、纵向浏览；枚举全部正在运行的程序，而非仅有音频会话的程序。已保存的屏蔽规则即使程序没运行也保留显示。
- 画质优先与帧率优先保持二选一；低延迟独立为细行开关，首次关闭，后续记住用户选择。
- 客户端仍读取唤起服务器 `/api/share/info` 的 `allowedQualities`，开始共享时再次验证。正式服务从绑定服务器配置读取权限，未改动。
- 临时测试服务器此前开放全部七档，现默认开放 720p30、1080p30、1080p60，可通过 `XGOATCAST_TEST_ALLOWED_QUALITIES` 配置。

## 验证

- MSVC x64 Release 编译成功。
- Windows 原生测试通过：URI 校验、进程树过滤、后台静音进程后续音频会话出现时的策略检查、三种界面离屏渲染、窗口/托盘启动退出、SDK 初始化及自定义音轨。
- 真实 WASAPI 合成音源测试：440 Hz 允许音源幅度 0.02214；880 / 1320 Hz 被屏蔽音源幅度约 0.0000063 / 0.0000042，均低于未屏蔽基线的 5%。只采集专用测试进程。
- 本地测试服务已重启，实际 HTTP 响应确认只返回三个配置档位。重启前没有活动共享；旧临时链接失效，需刷新测试页。
- 已查看主界面与软件管理面板离屏预览。离屏预览使用模拟画面源，不代表真实屏幕采集；不能验证 Windows 合成器最终边框效果。
- 未进行真实房间发布/观看以及真实 KOOK、黑盒语音兼容性测试。

后台静音程序可以提前按名称屏蔽；实际音频采集每 250 ms 更新进程与会话，只采集通过规则检查的进程树。进程名称或架构变化仍需真实软件兼容性验证。
