# 原生客户端细节审查

范围：保留已确认的双列来源、大预览、右侧设置与程序音频结构，核对当前原生渲染并集中修正。

| 发现 | 原因 | 修正 |
| --- | --- | --- |
| 开始按钮文字和时间偏左 | 用字符数乘固定值估算混合文字宽度 | 使用 DirectWrite 的真实字体尺寸，图标与文字整体居中；同样修复停止与打开网页按钮 |
| 麦克风底纹突兀 | 在统一设置表面上额外铺了一层纸白卡片 | 移除独立底板，保留设置区底色 |
| 开关规格不一致 | 麦克风／低延迟使用 44×26，程序音频使用 40×23 | 统一 40×23 与右侧位置；点击区域保留扩展 |
| 观看人数和单位空隙过大 | 固定数字框占 64 像素 | 按数字真实宽度排列单位 |
| 画质菜单高亮首项而非当前值 | 初始焦点写死为 0 | 打开时定位当前值；鼠标悬停后取消旧键盘高亮 |
| 开始按钮里的期限说明无法悬停查看 | 通用按钮提示先命中，遮蔽后加的倒计时提示 | 合并到按钮提示 |
| 刷新后选中的来源消失仍保留预览状态 | 仅清除 selected，未重置预览模式 | 返回来源选择状态 |

验证：沿用 Windows UI 回归与六种渲染，检查普通 DPI、150% DPI、共享窗口和菜单。画面为合成夹具；本轮不包含真实房间联调或完整屏幕阅读器认证。
