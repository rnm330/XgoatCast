# Windows 客户端 0.2.1 调整记录

本次是用户要求的客户端界面重排及画质选择位置调整。未改变现有登录或令牌方案。

## 完成

- 调起 URL 仅传站点、会话参数和客户端 ID；网页和本地测试页都不再选客户端画质。
- 客户端读取 `/api/share/info` 的 `allowedQualities`，只显示服务器开放的档位；在客户端选择并保存。开始共享时采用客户端所选档位，检查仍在开放列表内，再发布。
- 首次未注册网页唤起时弹出无边框客户端内提示；已注册时不常驻按钮。点「稍后」可从托盘菜单补启用。
- 新安装默认屏幕，窗口为第二入口；已保存的类别偏好继续保留。
- 每页两张 16:9 预览卡，SDK 缩略图请求 320×180；无缩略图时用绘制的显示器图标代替缺字方块。
- 声音开关移到预览后，开启时才显示屏蔽选项；复选框改为切换开关和选项卡。
- 客户端画质档位、画质优先、帧率优先、低延迟卡片都有用途提示；共享声音及模式仍受系统和服务器权限约束。
- 标题字体、悬停状态、右上角最小化与关闭分别采用小图标；最小化进入任务栏，关闭隐藏到托盘。
- 正式共享页的画质区标为浏览器共享画质；客户端按钮写明在客户端选择。
