# 自建共享面板

## 入口和行为

- 注册：`/panels/register`；找回管理密码：`/panels/recover`。
- 面板：`/<面板ID>`；管理：`/<面板ID>/admin`。
- 首页暂不展示自建共享面板入口，测试时直接访问注册路径。超管后台增加“自建面板”页，只返回 ID、名称、邮箱、创建时间及启停状态，不提供房间内容、观看/发布链接、声网凭证或授权码。
- ID 不区分大小写，5～16 位 ASCII 字母或数字；允许纯字母、纯数字和重复组合，禁止全部相同字符。系统路径与已存在的旧管理 ID 保留。ID 和邮箱不可更改；一个邮箱对应一个面板。
- ID 输入停顿 400ms 后查询可用性，过短或单一重复字符先在浏览器提示；创建时仍以数据库唯一约束为准。
- 邮箱验证成功后，在同一个 SQLite 事务中消费验证码并创建面板；无需审批。
- 注册、找回和修改管理密码均要求确认密码；新密码最少 8 位，至少包含一个大写字母、一个小写字母和一个数字。已有密码仍可登录。
- 授权码默认关闭，不设置业务位数限制，支持大小写敏感的字母、数字及符号。新授权码先经 SHA-256 再 bcrypt，避免 bcrypt 的 72 字节截断；兼容旧授权码哈希。开启后，访客必须先验证才能查看列表及创建房间。验证在当前浏览器保留 24 小时；改变授权码、关闭后重新开启或停用面板会使旧授权失效。
- 房间名称默认使用北京时间 `YYMMDDHHmmss`，例如 `260908025401`，可修改，不要求昵称。房间观看密码可选，默认留空。
- 列表只显示共享中和重连中的房间名称、在线人数和密码标记。待开始和已结束的房间不显示。
- 观看链接使用独立随机凭证，只检查房间密码，不检查面板授权码；观看凭证不能调用发布、停止和发布端心跳接口。
- 管理后台侧栏分为“面板设置 / 共享记录 / 个人资料”，密码修改放在个人资料内；记录仅在打开对应分栏时加载。
- 停用面板会结束现有共享并关闭 SSE 连接，禁止创建、列表访问及观看，管理员仍可登录查看停用状态。恢复启用保留配置，但不恢复已结束房间。
- 超管通过公开地址访问时遵守与普通访客相同的授权码和房间密码规则。

## SMTP 配置

优先在超管后台 → 全局配置 → 邮件服务保存 SMTP 主机、端口、加密方式、账号、密码或授权码及发件邮箱。保存后立即生效；密码不回显，留空保留。连接检查和测试邮件均使用已保存的配置。未保存后台配置时，仍兼容下列环境变量。后台配置保存在数据库中，备份按敏感配置保护。

## 容器更新与恢复

先构建镜像再替换容器，避免在停止旧容器后安装依赖。已建立的音视频继续通过声网传输，控制连接自动重试。启动时仅为共享中及心跳失联的房间提供最多 60 秒恢复窗口，并受最后一次持久化心跳后 90 秒的上限约束。恢复期限持久化，重复重启不延长同一窗口；手动停止、已结束、停用和 24 小时上限不被恢复逻辑绕过。

恢复期过后仍未收到发布端心跳的房间会结束。无人时间持久化，观众回归后清除；否则按面板原有无人超时关闭，即使发布页面仍打开也不会无限保留。观众稳定 ID 持久化去重，重连不增加累计加入数；后台在恢复期间明确提示人数暂未确认。原有峰值估算观看时长口径保留，不表示逐观众精确声网账单。首次从旧版升级无法补回旧进程从未持久化的观众标识。

页面对网关 502 等错误主动重建 EventSource，使用 1～2 秒随机间隔，避免原生 EventSource 进入 CLOSED 后永久停止。连续 120 秒无法取得房间状态时，页面结束共享/观看，防止控制服务长期不可达时仍持续占用声网资源。首次升级需要旧页面刷新后才能使用此客户端逻辑。浏览器验证覆盖了真实后端进程退出 10 秒、网关返回 502、发布/观看重连、去重及统计恢复；长时间失联退出使用加速计时验证。

## SMTP 环境变量兼容

在部署使用的 `.env` 中设置以下变量，并重启服务：

```dotenv
SMTP_HOST=smtp.example.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your-smtp-user
SMTP_PASS=your-smtp-password
SMTP_FROM=notify@example.com
```

- 465 使用隐式 TLS：`SMTP_SECURE=true`。
- 587 使用 STARTTLS：`SMTP_SECURE=false`。代码要求升级 TLS，不降级为明文发送。
- `SMTP_FROM` 应为服务商允许的发信地址；发信域名验证及 DNS 记录按服务商要求配置。
- 四个必要项 `HOST/USER/PASS/FROM` 未齐全时暂停注册和找回密码。已经存在的面板不受影响。
- 邮箱验证码有效期 10 分钟，最多错误尝试 5 次，使用后立即消费。
- 验证码用进程内随机密钥做 HMAC，数据库不保存明文验证码。服务重启后旧验证码失效，需要重新发送。
- 邮件发送连接 / 握手超时 10 秒、socket 超时 15 秒，最多同时发送 2 封，无额外邮件队列或常驻邮件进程。

如有反向代理，需要将其**实际可信地址或 CIDR**填入 `TRUST_PROXY`，让 Express 按真实访客 IP 限流。例如仅本机代理可使用 `TRUST_PROXY=loopback`；Docker 中应按实际代理地址配置。不要信任任意来源的转发头。未配置时使用直连地址，在代理后可能把多名访客视为同一 IP。

## 资源控制

- 音视频继续由声网承载；本站不转发音视频。
- 图片验证码使用 `svg-captcha` 在现有 Node.js 进程生成 SVG，不增加服务、浏览器渲染器或图像处理进程。验证码 5 分钟有效，一次尝试后作废，最多保留 600 条。
- 验证码每 IP 每分钟 12 次、全局每分钟 120 次。
- 邮件发送每 IP 15 分钟 5 次、每邮箱 60 秒 1 次 / 24 小时 10 次、全局每分钟 30 次；最多保留 1000 条未清理验证码记录，发送时删除过期记录。
- 限流器最多 10000 个内存条目，请求时按分钟清理过期项，不增加定时扫描数据库的任务。服务重启重置短期内存限流。
- 注册 / 找回提交每 IP 15 分钟 10 次；登录 / 授权码 / 房间密码尝试每 IP 每分钟 10 次；最多同时执行 4 个密码哈希或比较任务，使用异步 bcrypt 接口。
- 创建共享每 IP 间隔至少 5 秒、每面板每分钟最多 30 次。不限制正在共享的房间总数。
- 正在进行的共享每批 50 条，使用稳定游标自动向下续载并去重，不显示上一页 / 下一页按钮。每 20 秒刷新已加载部分，页面隐藏时停止刷新；管理记录和超管列表按需加载，不轮询。
- 活跃房间游标利用 `(server_id,created_at,id)` 的活跃状态部分索引；历史分页利用 `(server_id,created_at)` 索引，避免每次读取所有历史会话。
- 复用现有会话状态维护、超时回收和 SSE，不为面板列表另建长连接或后台任务。面板事件不会投递给外部机器人。

这是单进程 SQLite 部署方案；若未来增加多个 Node.js 副本，需要先共享验证码/限流状态，不能直接把内存验证状态跨副本使用。

## 验证

```bash
npm run build
npm test
# 展开本功能的具体断言输出
cd server
node --require ts-node/register test/panels.spec.ts
node --require ts-node/register test/panels-http.spec.ts
```

测试使用临时数据库和模拟邮件发送，不访问生产数据、不发送真实邮件。HTTP 测试需要允许监听本机临时端口。

上线前还需用真实 SMTP 验证收信，并使用真实声网项目在浏览器实测屏幕/声音共享、密码观看和停用后的断开行为。本次没有部署。

## 本地交互测试服

构建后运行 `npm run preview:panels`：

- 注册：`http://localhost:3521/panels/register`
- 演示面板：`http://localhost:3521/demo123`
- 演示管理：`http://localhost:3521/demo123/admin`，初始密码 `PreviewPanel2026`
- 超管：`http://localhost:3521/super`，测试密码 `PreviewSuper2026`
- 本地测试收件箱：`http://localhost:3522`。任意测试邮箱的验证码只写入该测试收件箱，不实际发信；刷新收件箱即可读取。

启动器仅绑定本机地址，使用系统临时目录下 `xgoatcast-panels-preview` 的独立数据库和环境配置，不读取项目 `.env`。演示面板初次启动时建立；后续启动保留测试配置和账号。真实音视频测试需要自行填入声网 App ID / Certificate。测试 SMTP 替换仅存在于这个预览进程，不修改生产 SMTP 实现。
